# Ирис — сайт цветочного магазина

Простой сайт-визитка цветочной лавки на чистых **HTML / CSS / JS**, без сборщиков и зависимостей — открывается прямо в браузере.

## Что внутри

- `index.html` — разметка страницы
- `style.css` — стили и дизайн
- `script.js` — каталог, корзина, фильтры, форма заказа
- `README.md` — этот файл

## Возможности

- Каталог букетов с фильтрами по категориям
- Корзина (добавление, изменение количества, удаление, подсчёт суммы)
- Форма заказа с проверкой заполнения полей
- Адаптивная вёрстка (мобильные, планшеты, десктоп)

> Корзина и форма работают полностью на стороне браузера (без сервера и базы данных) — это фронтенд-демо. Чтобы заказы реально отправлялись вам на почту или в CRM, добавьте бэкенд или сервис форм (например, Formspree, Getform) и подключите его в `script.js` в обработчике `orderForm.addEventListener("submit", ...)`.

## Как загрузить на GitHub

### Вариант 1 — через сайт GitHub (без консоли)

1. Зайдите на [github.com](https://github.com) и нажмите **New repository**.
2. Дайте имя репозиторию, например `flower-shop`, и создайте его (без файлов README/gitignore, чтобы не было конфликтов).
3. На странице пустого репозитория нажмите **uploading an existing file**.
4. Перетащите туда файлы `index.html`, `style.css`, `script.js`, `README.md`.
5. Нажмите **Commit changes**.

### Вариант 2 — через терминал (git)

```bash
cd flower-shop
git init
git add .
git commit -m "Первая версия сайта цветочного магазина"
git branch -M main
git remote add origin https://github.com/ВАШ-АККАУНТ/flower-shop.git
git push -u origin main
```

## Как опубликовать сайт бесплатно (GitHub Pages)

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите источник **Deploy from a branch**.
3. Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://ВАШ-АККАУНТ.github.io/flower-shop/`

## Как изменить контент

- Ассортимент и цены — массив `BOUQUETS` в начале `script.js`.
- Отзывы — массив `REVIEWS` там же.
- Контакты и адрес — секция `#contact` в `index.html`.
- Цвета и шрифты — переменные `:root` в начале `style.css`.
